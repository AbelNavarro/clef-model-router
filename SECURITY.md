# Security policy

This mod handles a Cloudflare API token and sees every prompt you send to Claude Code. Please report anything that could leak either, or that lets a prompt or a response change the mod's behaviour beyond the documented routing.

**Report privately:** use GitHub's [private vulnerability reporting](https://github.com/AbelNavarro/clef-claude-router/security/advisories/new). Please don't open a public issue. Expect a first answer within a week.

What the mod sends and stores, and how credentials are handled, is documented in [docs/PRIVACY.md](docs/PRIVACY.md).
